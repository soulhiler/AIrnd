# Эксперимент 01 — Проверка промпта для AI

## Что это

Мы хотим проверить: меняет ли наш промпт поведение Claude в обычной работе? Сравниваем две ветки диалога:

- **Без промпта** — обычный новый диалог с Claude.
- **С промптом** — новый диалог, в первое сообщение вставлен наш промпт.

В обе ветки задаём **один и тот же** вопрос. Сравниваем ответы.

## Как запустить тест

### Простой вариант (15 минут)

1. Открой Claude в **новой ветке** диалога. Назови её «без промпта».
2. Открой Claude во **второй новой ветке**. Назови её «с промптом».
3. Во вторую ветку **вставь сообщением** содержимое файла [`system-prompt-full.md`](system-prompt-full.md) (от слова «Привет» до «конец инструкций»). Claude подтвердит, что понял.
4. **В обе ветки** отправь один и тот же тестовый вопрос. Возьми **вопрос 1** из [`test-scenarios.md`](test-scenarios.md):

   ```text
   Нужен сервер для индексации файлов в репозитории и поиска по ним. Делай.
   ```

5. Сравни ответы. Запиши, что заметил.

### Что искать в сравнении

- **Длина ответа.** Где короче?
- **Вопросы перед действием.** Где задаёт уточняющие вопросы, а где сразу пишет код?
- **Количество фич.** Где минимум, где «давайте сделаем всё»?
- **Варианты выбора.** Где показывает варианты с плюсами и минусами, где выбирает молча?
- **Прямота про ограничения.** Где говорит «эта фича лишняя», где добавляет всё подряд?

## Что ожидаем увидеть

### От ветки «без промпта»

- Сразу начинает писать код.
- Добавляет много фич (теги, поиск по смыслу, переранжирование результатов).
- Архитектурные решения принимает молча.
- Длинный ответ, 1000+ строк кода.

### От ветки «с промптом»

- Сначала задаёт уточняющие вопросы (какие файлы? сколько? зачем?).
- Применяет тест «без этой фичи — что будет?» к каждой возможности.
- На архитектурных моментах — даёт 2-3 варианта с плюсами/минусами, ждёт твой выбор.
- Короткий стартовый набор фич, только необходимое.

## Если результат как ожидаем

Промпт работает — методология трека 4 действительно меняет поведение AI. Можно использовать промпт в любых других проектах с AI.

## Если результата нет

Промпт **не работает** или работает слабо. Это тоже важный результат — значит, нужны другие способы (внешние проверки, инструменты), а не только текст в начале диалога.

## Связь с треком 4

Этот тест проверяет всю теоретическую работу трека 4:

- Принцип «меньше — лучше» (из Брукса, ТРИЗ, теории надёжности машин, тектологии Богданова).
- Тест из трёх вопросов (по Аршинским).
- 6 правил из [CLAUDE.md](../../../../CLAUDE.md).
- Эстетический взгляд (Ершов).
- Роли «архитектор / помощник» (ADR 0002 трека 4).

Сжато в один промпт. Если работает — методология **применима**, не только теоретическая.
