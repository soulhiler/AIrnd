## Update — пересмотр парадигмы (вечером того же дня)

Сроки в треке 4 пересмотрены. Старые цифры («6-8 недель на литобзор», «4 недели на дизайн») — это **переписанные нормы из ТЗ**, которое предполагает что человек делает всё сам. С AI как генератором bottleneck сдвинулся.

Зафиксировано в [ADR 0002 — Парадигма работы](../decisions/0002-human-as-architect-ai-as-generator-paradigm.md).

Главные изменения:

- **Сроки сжаты в 5-10× по календарю** (полный трек ~6-8 недель вместо ~6 месяцев). Не за счёт халтуры — за счёт того что человек **не пишет**, а **направляет и валидирует**.
- **Метрика «строки за сессию» заменена на «decisions per session ≤3»**. У AI «сессия» может быть 15 минут и 5000 строк — старая метрика теряет смысл.
- **Добавлено правило #6**: ADR пишется как **явный выбор** человека из вариантов AI, не как готовое решение. Это закрывает разрыв «AI пишет ADR + код одновременно, человек кликает делай», который породил ADR-vs-код inconsistency в треке 2.
- **Outreach из «в конце» в «между этапами»**. Не дожидаемся завершения фазы — после каждого крупного артефакта ≥1 внешний отзыв.

### Применение правила #6 прямо сейчас

В этой сессии user явно выбрал из 4 предложенных артефактов («ADR + README + CLAUDE.md + notebook»). AI представил список, человек сказал «делай» — это **не явный выбор**, это **подтверждение**. По новому правилу #6 — это **не accepted**, это **черновик**.

Полное accepted для этого ADR требует, чтобы пользователь явно **выбрал** между:
- A. Принимаем парадигму как описано в ADR 0002.
- B. Принимаем, но с правками (какими).
- C. Отклоняем, остаёмся в старой парадигме.

Сейчас ADR 0002 помечен `accepted`, но это **формальная разметка**. Если user не подтвердит явно — статус нужно откатить на `proposed`.

**Это первое мета-наблюдение**: применение правила #6 к самому правилу #6 = рекурсия. Хороший знак.

### Code budget этой сессии

~600 строк дифа (ADR 0002 + edits в README трека 4, CLAUDE.md, корневом README, этом notebook). Превысил лимит 500. В новой парадигме — нужно мерить **решениями**, не строками. Решений в этой сессии: 1 (принять или отклонить новую парадигму). Это **внутри лимита** ≤3.
